# Печатное издание

Здесь лежит конвейер сборки оригинал-макета учебного пособия в формате,
который принимает ИПЦ НГУ.

Пособие выходит **в двух частях**: одна книга на 420 страниц формата А5
неудобна в работе, а граница между частями естественно ложится на темы
рабочей программы.

| Часть | Название | Разделы | Объём |
|---|---|---|---|
| 1 | Инструменты и основы | помощники, Linux, алгоритмы, вычислительная физика, Python, практики разработки | ~230 стр. |
| 2 | Данные, ускорение и практика | обработка данных, машинное обучение, ускорение кода, примеры СО РАН, практикум | ~195 стр. |

## Как собрать

```bash
bash print/build.sh
```

Собирает обе части; можно указать номер — `bash print/build.sh 1`.
Результат: `print/build/Разработка и применение ПО в физических исследованиях. Часть N.pdf`

## Что нужно установить

```bash
brew install pandoc librsvg
```

Плюс TeX Live с XeLaTeX (`brew install --cask mactex` или `basictex`
с пакетами `fontspec`, `polyglossia`, `unicode-math`, `fvextra`, `titlesec`,
`fancyhdr`, `microtype`, `xurl`).

Шрифты: Times New Roman, Arial, Menlo (входят в macOS), математический
`texgyretermes-math.otf` (входит в TeX Live).

## Из чего состоит

| Файл | Назначение |
|---|---|
| `build.sh` | Точка входа: готовит markdown и запускает вёрстку |
| `prepare.py` | Собирает главы одной части в порядке `src/SUMMARY.md` и готовит их к печати |
| `template.tex` | Шаблон оригинал-макета: титул, оборот, полоса набора, стили |
| `build/` | Результат сборки (в git не хранится) |

## Что делает `prepare.py`

Электронная книга и бумажная — это разные носители, поэтому исходный
markdown приходится готовить:

* главы склеиваются в порядке `SUMMARY.md`, уровни заголовков приводятся
  к структуре «часть — глава — раздел»;
* вырезается интерактивный HTML (скрипты Plotly, стили), а HTML-таблицы
  из выводов pandas переводятся в markdown-таблицы с обрезкой длинных
  ячеек — иначе они не помещаются в полосу набора шириной 115 мм;
* картинки, зашитые в markdown как base64, извлекаются в файлы; SVG
  переводится в PDF (`rsvg-convert`), потому что XeLaTeX не умеет SVG;
* формулы `\\( \\)` приводятся к обычному TeX, убираются вложенные
  окружения `equation` внутри `$$` (MathJax их терпит, LaTeX — нет);
* длинные распечатки результатов работы программ сокращаются до 12 строк;
* убираются эмодзи и символы, которых нет в Times New Roman;
* относительные ссылки на другие главы заменяются их названиями.

## Чем книга отличается от сайта

Электронная версия остаётся полной. Из печатного издания вынесено то,
что на бумаге не работает или дублируется, — всё это описано в начале
`prepare.py` и собрано в одном месте:

* **экспресс-курс Python** (`basics`, `numpy`, `matplotlib`) — дословно
  дублирует разделы «Погружаемся в Python» и «Обрабатываем данные»;
* **длинные листинги** — обрезаются (14 строк в обычных главах, 8 —
  в выгрузках из Jupyter) с пометкой и ссылкой на сайт;
* **распечатки результатов** — до 6 и 3 строк соответственно;
* **интерактивные графики Plotly** — на бумаге виден только код без
  результата, поэтому раздел заменён ссылкой;
* **разборы задач** в главах про деревья и графы — оставлено по две,
  остальные перечислены условиями;
* **практикум** — печатается формулировка задания, развёрнутые
  требования остаются на сайте.

Чтобы вернуть что-то в печать, поправь соответствующую константу
в начале `prepare.py` (`SKIP`, `NOTEBOOKS`, `DROP_SECTIONS`,
`KEEP_TASKS`, `BRIEF`, `CODE_LIMIT`, `OUTPUT_LIMIT`).

## Требования ИПЦ НГУ, заложенные в `template.tex`

Формат А5 (60×84 1/16), страница 148×210 мм, полоса набора 115×175 мм,
поля 17 мм сверху/слева/справа и 20 мм снизу, Times New Roman 10 пт
(требования допускают 10–11),
одинарный интервал, абзацный отступ 5 мм, колонцифра внизу по центру,
автоматические переносы, выравнивание по ширине.

## Что нужно заполнить перед сдачей в печать

В `template.tex` оставлены места под данные, которые выдаёт издательство:

* **УДК и ББК** — уточнить в библиотеке НГУ (сейчас стоят предварительные
  `004.4:53(075.8)` и `32.973-018я73`);
* **ISBN** — присваивает ИПЦ: для многотомного издания нужны общий
  номер и номер каждой части (сейчас `978-5-4437-XXXX-X` и
  `978-5-4437-YYYY-Y`);
* **рецензент** — учёная степень, звание, фамилия;
* **протокол заседания кафедры** — номер и дата;
* **выходные данные** — тираж, заказ, дата подписания в печать,
  учётно-издательские и условные печатные листы.

Схема расчёта листов (формат А5): `страниц / 16` = уч.-изд. л.,
затем `× 0,93` = усл. печ. л.
