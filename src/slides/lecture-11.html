Интерактивность

Изложение. Лекция состоит из шести частей. Первая объясняет, зачем строить график, если статистики уже посчитаны, и как выбрать вид графика под задачу. Вторая посвящена устройству фигуры Matplotlib, основным видам графиков и сохранению в файл. Третья — оформлению для статьи: подписям с формулами, погрешностям, компоновке и стилю. Четвёртая — полям на сетке и палитрам. Пятая — статистическим графикам pandas и seaborn. Шестая — интерактивным графикам Plotly и HoloViews.

Цель лекции

Показывать данные так, чтобы график не вводил в заблуждение ни автора, ни читателя

Для собственного анализа график строится быстро и сразу просматривается, для статьи — оформляется по правилам журнала и сохраняется в векторном формате, для коллег — становится интерактивной страницей. Во всех трёх случаях вид графика, масштаб осей и палитра выбираются по смыслу данных.

Изложение. График служит трём целям. Первая — разведка: физик строит десятки графиков для себя, чтобы увидеть данные, найти выбросы и проверить расчёт, и здесь важна скорость. Вторая — публикация: график в статье оформляется по правилам журнала, подписи содержат единицы и формулы, а файл сохраняется в векторном формате. Третья — совместная работа: интерактивная страница позволяет коллеге навести курсор, прочитать число и приблизить фрагмент без Python. Общее для всех трёх случаев одно: вид графика, масштаб осей и палитра выбираются по смыслу данных, иначе график скрывает структуру данных или создаёт видимость несуществующей.

Для физика

Статья — Matplotlib, разбор сырых данных — Plotly или HoloViews, мониторинг установки — Panel.

Пояснение

Основа почти всех статичных графиков Python — Matplotlib: seaborn и pandas строят поверх него.

Изложение. Библиотек для построения графиков в Python много, но физику обычно достаточно нескольких. Matplotlib — основа статичной графики: фигура, оси и любой вид графика с сохранением в растровый или векторный файл. Поверх него построены seaborn, строящий статистические графики прямо из таблицы, и метод plot таблиц pandas для быстрого взгляда на столбцы. Plotly строит интерактивный график в браузере с подсказками, масштабированием и трёхмерными сценами и сохраняет его в самодостаточный HTML. Bokeh и Panel предназначены для интерактивных страниц и панелей мониторинга с сервером на Python. HoloViews предлагает описывать данные, а не график, и отрисовывает один и тот же объект разными бэкендами. Для статьи обычно выбирают Matplotlib, для разбора сырых данных — Plotly или HoloViews, для мониторинга установки — Panel.

Важно

Сводные статистики не заменяют взгляда на данные: график — первый шаг анализа, а не последний.

Изложение. В 1973 году статистик Ф. Энскомб опубликовал четыре набора по одиннадцать пар чисел, у которых совпадают средние по x и по y, дисперсии, коэффициент корреляции и прямая регрессии y = 0,5x + 3. По таблице статистик наборы неотличимы, а на графике различаются полностью: один — линейная зависимость с шумом, другой — гладкая нелинейная кривая, третий — точная прямая с одним выбросом, четвёртый — вертикальный столбик точек и одна далёкая точка, которая одна задаёт наклон. Пример показывает, что сводные статистики не заменяют взгляда на данные: график строится до вычисления статистик, чтобы понять, какие статистики имеют смысл. Современный вариант того же опыта — набор «Datasaurus Dozen» 2017 года, где облака точек самой разной формы, вплоть до рисунка динозавра, имеют одинаковые до сотых средние, стандартные отклонения и корреляцию.

Пояснение

Каталог видов графиков по назначению — «Периодическая таблица методов визуализации» (visual-literacy.org).

Важно

Круговые и объёмные диаграммы сравнивать трудно: длину глаз оценивает точнее, чем угол и площадь.

Изложение. Вид графика выбирается не по вкусу, а по задаче. Распределение одной величины показывает гистограмма, а сравнение распределений нескольких групп — ящики с усами или скрипичные диаграммы. Зависимость одной величины от другой изображает линия, связь двух измеренных величин — точечная диаграмма, измерения с погрешностями — точки с отрезками ошибок. Поле на регулярной сетке показывают цветовой картой или изолиниями. Когда параметров больше трёх, применяют параллельные координаты, где каждый параметр получает свою ось. Каталог из сотни видов графиков, сгруппированных по назначению, — «Периодическая таблица методов визуализации» сайта visual-literacy.org. Круговые и объёмные диаграммы для сравнения величин подходят плохо: длину отрезка глаз оценивает точнее, чем угол сектора или площадь.

Важно

Обрезанная ось у столбцовой диаграммы преувеличивает разницу в разы.

Для физика

Спектры и профили пучка с большим динамическим диапазоном — в логарифмическом масштабе.

Изложение. Несколько правил делают график честным. Ось подписывается величиной и единицами измерения. Масштаб выбирается по смыслу: логарифмический — для величин, меняющихся на порядки, линейный — для остальных; ось столбцовой диаграммы начинается с нуля, потому что длина столбца и есть величина, а обрезанная ось преувеличивает разницу в разы. Панели, которые сравнивают между собой, получают общие шкалы. Две величины с разными единицами, например давление и ток, строят на двух осях одна под другой с общей шкалой времени, а не на двух шкалах y одних осей: соотношение независимых шкал выбирается произвольно и может создать видимость связи. Палитра выбирается по смыслу величины, что разобрано в четвёртой части. Наконец, на графике нет ничего, что не несёт данных: объём, тени, фоновые рисунки и лишние рамки отвлекают и искажают. Э. Тафти называет это отношением «чернил данных» ко всем чернилам рисунка, которое должно быть возможно большим.

Изложение. Вторая часть посвящена Matplotlib: двум интерфейсам библиотеки, устройству фигуры, основным видам графиков и сохранению фигуры в файл на машине без экрана.

Два

интерфейса

pyplot: скрытая текущая фигура

import matplotlib.pyplot as plt
 
plt.plot(t, current)
plt.xlabel('Время, мкс')
plt.savefig('a.png')

Объекты: фигура и оси названы явно

fig, ax = plt.subplots(figsize=(7, 3))
ax.plot(t, current)
ax.set_xlabel('Время, мкс')
fig.savefig('a.png')

Пояснение

Явные fig и ax — в любом коде длиннее нескольких строк: видно, к каким осям относится вызов.

Изложение. У Matplotlib два интерфейса. Первый, pyplot, унаследован от MATLAB: он хранит скрытую текущую фигуру и текущие оси, и команды наподобие plt.plot и plt.xlabel рисуют в них. Это удобно для одной строки в интерактивном сеансе, но в коде из нескольких фигур не видно, куда относится очередной вызов. Второй интерфейс объектный: plt.subplots возвращает фигуру fig и оси ax, и построение выполняется методами осей — ax.plot, ax.set_xlabel, — а сохранение методом фигуры fig.savefig. Имена методов немного различаются: plt.xlabel соответствует ax.set_xlabel. В любом коде длиннее нескольких строк используется объектный интерфейс; глава книги и все демонстрации лекции написаны в нём.

Пояснение

На одной фигуре несколько осей: plt.subplots(2, 1) возвращает фигуру и массив из двух осей.

Изложение. Фигура Figure — весь холст: поля, общий заголовок и то, что в итоге записывается в файл. На ней размещаются оси Axes — прямоугольные области с собственной системой координат, в которых и строится график. У осей есть шкалы XAxis и YAxis с пределами, делениями и подписями. Всё, что нарисовано, — линии Line2D, текст, легенда, прямоугольники столбцов — является художником, Artist, и у каждого есть свои свойства: цвет, толщина, прозрачность. Построение выполняется методами осей, сохранение — методом фигуры. Одна фигура может содержать несколько осей: plt.subplots(2, 1) возвращает фигуру и массив из двух осей, расположенных одна над другой.

Основные

виды графиков

ax.plot(t, current)               # линия
ax.scatter(x, y, s=10)            # точки
ax.errorbar(k, s, 0.02, fmt='o')  # погрешности
ax.hist(age, bins=16)             # гистограмма
ax.bar(labels, values)            # столбцы

Пояснение

Каждый метод возвращает созданный объект: линию, набор точек, изображение — для последующей настройки.

Для физика

Галерея matplotlib.org/stable/gallery: вид графика подбирается по картинке, код берётся готовым.

Изложение. Основные виды графиков — методы осей: plot рисует линию, scatter — точки, размер и цвет которых могут зависеть от данных, errorbar — точки с отрезками погрешностей, hist — гистограмму, bar — столбцы, fill_between — полосу между двумя кривыми, например огибающую пучка, imshow — двумерный массив как изображение, contour — изолинии. Масштаб оси меняют set_xscale и set_yscale, в том числе на логарифмический. Каждый метод возвращает созданный объект — линию, набор точек, изображение, — у которого затем меняют свойства. Для незнакомого вида графика удобнее всего галерея на сайте Matplotlib: изображение подбирается визуально, а код примера берётся готовым.

Важно

На машине без экрана Matplotlib выбирает бэкенд Agg: plt.show() ничего не покажет, графики сохраняются в файлы.

Пояснение

В Jupyter фигура показывается под ячейкой сама, savefig нужен только для файла.

Изложение. Метод savefig определяет формат по расширению файла. PNG — растр: число точек равно размеру фигуры в дюймах, умноженному на плотность dpi, — фигура 8 × 3,2 дюйма при 150 dpi даёт 1200 × 480 точек; для слайдов и веба достаточно 150–300 точек на дюйм. SVG и PDF — векторные форматы, которые не размываются при увеличении; PDF содержит шрифты и вставляется в статью, в том числе в LaTeX. По умолчанию текст в SVG записывается кривыми, и подписи правятся в редакторе как текст лишь при rcParams['svg.fonttype'] = 'none'; в PDF встраиваются шрифты Type 3, а для издательств, требующих шрифтов TrueType, задают pdf.fonttype = 42. Плотное облако точек в векторном файле растеризуют аргументом rasterized=True: точки сохраняются растром, а оси и подписи остаются векторными, и PDF со ста тысячами точек уменьшается в десятки раз. Перед сохранением tight_layout подбирает поля, чтобы подписи не обрезались краем. Отображение фигуры зависит от бэкенда. На машине без графического экрана, такой как стенд или вычислительный сервер, Matplotlib выбирает бэкенд Agg, рисующий только в файлы, и plt.show() ничего не покажет. В Jupyter фигура выводится под ячейкой сама, а savefig нужен лишь для файла.

Методы возвращают оси Matplotlib, поэтому дальнейшее оформление — логарифмический масштаб, подписи, пределы — выполняется методами этих осей. На логарифмической оси нулевые значения не изображаются: точки семи пассажиров с известным возрастом и нулевой платой за проезд исчезают с графика без предупреждения. Для быстрого взгляда на журнал или таблицу измерений достаточно одной строки, а для статьи те же оси оформляются по правилам третьей части.

Изложение. Plotly строит график в браузере поверх библиотеки plotly.js. Объекты graph_objects дают полный контроль над каждой линией, а модуль plotly.express строит типичные графики из таблицы одной строкой, как seaborn; числовой столбец в аргументе color, например класс каюты Pclass, он окрашивает непрерывной шкалой, а строковый — качественной палитрой. С include_plotlyjs='cdn' страница загружает plotly.js из сети и весит десятки килобайт, со значением True библиотека встраивается внутрь, и файл вырастает до нескольких мегабайт, зато открывается без сети. Миллион точек обычный Scatter отрисовывает медленно, и для больших массивов предусмотрен Scattergl с отрисовкой на видеокарте. Статичный PNG или PDF из фигуры Plotly сохраняет метод write_image; в Plotly 7 он требует пакета kaleido версии 1 и установленного браузера Chrome.

Пояснение

Подписи осей с единицами HoloViews берёт из описания данных: «Радиус пучка (мм)».

Изложение. HoloViews построен на принципе «описывать данные, а не график»: пользователь указывает, что является аргументом, что значением и в каких они единицах, а библиотека выбирает представление. Измерения Dimension несут подпись и единицы, которые попадают на оси и в подсказки. Элемент Curve задаёт непрерывную зависимость, Scatter и Points — дискретные точки, Image — величину на сетке. Оператор + размещает графики рядом, оператор * накладывает их в одних осях. HoloMap превращает параметр в слайдер. Он принимает словарь, где каждому значению параметра сопоставлен элемент HoloViews, например Curve, а не массив; кадры вычисляются заранее и сохраняются в HTML, работающий без Python, а библиотеки BokehJS и Panel страница загружает из сети. Один и тот же объект отрисовывается разными бэкендами — интерактивным bokeh, matplotlib или plotly. На слайде скан огибающей при четырёх жёсткостях соленоидов, сохранённый через бэкенд matplotlib: подписи «Положение (м)» и «Радиус пучка (мм)» HoloViews составил сам из описания измерений.

Пояснение

Кадр меняет данные готовых художников: set_data и set_ydata быстрее, чем новый plot на каждом шаге.

Пояснение

GIF записывает Pillow, MP4 — ffmpeg, который ставится отдельно.

Для физика

Эволюция волнового пакета во времени или огибающей вдоль тракта.

Изложение. Matplotlib строит и анимацию. FuncAnimation вызывает функцию update для каждого кадра; функция меняет данные уже созданных художников — set_ydata у линии, set_data у точек, set_array у изображения, — что намного быстрее, чем строить график заново. Готовая анимация сохраняется методом save: GIF записывает библиотека Pillow, поставленная вместе с Matplotlib, а MP4 — программа ffmpeg, которую устанавливают отдельно. В блокноте Jupyter анимацию показывает вызов HTML(anim.to_jshtml()) из модуля IPython.display или параметр rcParams['animation.html'] = 'jshtml'; без них при бэкенде inline, принятом в Jupyter по умолчанию, под ячейкой выводится только неподвижный кадр. Для физика это способ показать эволюцию: волновой пакет во времени, огибающую пучка вдоль тракта, распределение частиц по шагам расчёта.
