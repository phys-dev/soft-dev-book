# GitHub Copilot

Из трёх форм инструментов, разобранных выше, студенту проще всего начать с плагина к редактору. Разберём подробно самый распространённый из них — не потому, что он лучший, а потому, что он бесплатен по студенческой подписке и ставится в среду, которая у тебя уже открыта.

## 🤖 Что такое GitHub Copilot?

**GitHub Copilot** — плагин к редактору, который дописывает код за тобой. Его сделала компания GitHub вместе с OpenAI, и с ним массовый разработчик познакомился раньше, чем с чат-ботами — первая публичная версия вышла в 2021 году, за полтора года до ChatGPT.

> **Проще говоря:** Copilot — умное автодополнение, которое видит контекст всего файла, а не только текущую строку.

## 🎯 Зачем Copilot студентам?

Начинаем мы с Copilot по простой причине. Студентам он бесплатен, а значит, попробовать его можно прямо сегодня, не заводя платных подписок.

Пользы от него на этапе учёбы три. Во-первых, он снимает трение с синтаксисом — не нужно каждый раз лезть в документацию за порядком аргументов, по контексту он предложит правильный вызов, а ты запомнишь его, увидев несколько раз. Во-вторых, он неплохо помогает сдвинуться с мёртвой точки, когда смотришь на пустой файл и не знаешь, с чего начать; даже неидеальная заготовка даёт, от чего оттолкнуться. В-третьих, его предложения — способ увидеть, как принято писать на языке, который ты знаешь плохо. Для физика, которому раз в год приходится править чужой код на C++, это заметное подспорье.

Есть и оговорка, о которой стоит помнить с первого дня. Всё сказанное работает, только если ты читаешь то, что он предлагает. Принятое не глядя предложение — не сэкономленное время, а отложенная отладка.

## 💡 Как эффективно использовать Copilot

### Базовые приёмы работы

Единственный рычаг управления здесь — контекст, который видит модель: открытый файл, соседние вкладки и твои комментарии. Отсюда и приёмы.

1. **Комментируй свои намерения**:
   ```python
   # Напиши функцию для расчёта среднего значения списка
   # Copilot предложит:
   def calculate_average(numbers):
       return sum(numbers) / len(numbers) if numbers else 0
   ```

2. **Создавай шаблоны функций**:
   ```javascript
   function calculateCircleArea(radius) {
     // Copilot предложит:
     return Math.PI * radius * radius;
   }
   ```

3. **Работа с библиотеками**:
   ```python
   import numpy as np
   # Создать массив из 10 случайных чисел от 1 до 100
   # Copilot предложит:
   arr = np.random.randint(1, 100, 10)
   ```

### Продвинутые сценарии

Дальше начинается то, ради чего Copilot обычно и ставят. Он неплохо справляется с однообразной работой вокруг уже написанного кода — тестами и переписыванием готовых кусков.

**Генерация тестов**:
```python
# Функция сложения двух чисел
def add(a, b):
    return a + b

# Напиши тесты для этой функции
# Copilot предложит:
def test_add():
    assert add(2, 3) == 5
    assert add(-1, 1) == 0
    assert add(0, 0) == 0
```

**Рефакторинг кода**:
```javascript
// Старый код
function processData(data) {
    let result = [];
    for (let i = 0; i < data.length; i++) {
        if (data[i].active) {
            result.push(data[i].value * 2);
        }
    }
    return result;
}

// Добавь комментарий: "Рефакторинг с использованием map и filter"
// Copilot предложит:
function processData(data) {
    return data
        .filter(item => item.active)
        .map(item => item.value * 2);
}
```

## 📚 Примеры для учебных задач

Два примера того, как это выглядит на типичных заданиях второго курса. Комментарий задаёт задачу, Copilot дописывает остальное; сравни предложенное с тем, что написал бы сам.

### Для курса по алгоритмам
```python
# Реализуй быструю сортировку на Python
# Copilot предложит:
def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)
```

### Для курса по физике
```python
# Рассчитать траекторию движения тела под углом к горизонту
# Copilot предложит:
def calculate_trajectory(initial_velocity, angle_degrees, time_steps):
    import math
    g = 9.81
    angle_rad = math.radians(angle_degrees)
    vx = initial_velocity * math.cos(angle_rad)
    vy = initial_velocity * math.sin(angle_rad)
    
    trajectory = []
    for t in time_steps:
        x = vx * t
        y = vy * t - 0.5 * g * t**2
        if y < 0:
            break
        trajectory.append((x, y))
    return trajectory
```

## ⚠️ Важные ограничения и предостережения

### Где Copilot ошибается
1. **Пишет не самый эффективный код** — предложение нужно читать глазами, а не принимать нажатием Tab
2. **Предлагает устаревшие подходы** — их в обучающих данных больше, чем свежих; сверяйся с актуальной документацией
3. **«Галлюцинирует»** — придумывает несуществующие библиотеки, методы и аргументы

### Академическая честность

Правила у курсов разные, и выяснять их надо заранее, а не на защите. Общая рамка простая: Copilot — инструмент обучения, а не способ сдать задание, в котором ты не разобрался. Спроси у преподавателя, что разрешено на его курсе, и в любом случае разбирай сгенерированный код до того, как он попадёт в сдаваемую работу.

## 🏆 Лучшие практики для студентов

Всё сказанное сводится к пяти рабочим привычкам:

1. **Формулируй задачу точно** — чем конкретнее комментарий, тем ближе предложение к тому, что нужно
2. **Читай предложение целиком** — прежде всего граничные случаи: пустой список, деление на ноль, отсутствующий файл
3. **Проверяй тестом, а не взглядом** — короткий тест на паре значений отвечает надёжнее, чем внимательное чтение
4. **Отдавай ему шаблонное** — разбор аргументов командной строки, чтение форматов данных, однотипные графики
5. **Смотри не только на первый вариант** — Copilot показывает одно решение из многих, и не всегда лучшее

## 📝 Заключение

Copilot экономит время на том, что ты и так умеешь: на шаблонном коде, на синтаксисе плохо знакомого языка, на первой заготовке в пустом файле. Понимания он не добавляет — понимание остаётся твоей работой, и от того, делаешь ты её или нет, зависит, окажется он помощником или костылём.

**Главный принцип:** пользуйся Copilot, чтобы **углубить понимание**, а не чтобы **обойтись без него**.
