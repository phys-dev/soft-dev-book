# Нейронные сети

Классические алгоритмы хорошо работают там, где признаки заданы человеком: размер пучка, ток корректора, энергия события. Но если признаки нужно извлекать из сырого сигнала — изображения с камеры, осциллограммы, спектра, — их приходится придумывать вручную, и качество упирается в изобретательность физика. Нейронные сети это ограничение и снимают — они учат признаки сами.

Начнём с математической модели нейрона и функций активации, соберём из нейронов многослойную сеть и разберём, как она обучается методом обратного распространения ошибки (backpropagation). Дальше — оптимизаторы (SGD, Adam, RMSProp), нормализация данных и весов, способы регуляризации против переобучения.

## 1. Нейрон и функции активации

### Математический нейрон
Математический нейрон концептуально похож на биологический. Он принимает входные сигналы, умножает их на веса и пропускает через функцию активации.

Возьмём пример. Предсказать, сдаст ли студент экзамен, по трём признакам:
*   \\(X_1\\) — Задавал вопросы на парах (1/0).
*   \\(X_2\\) — Попал к лектору на экзамене (1/0).
*   \\(X_3\\) — Сдал лабы (1/0).

Логика задачи может быть следующей:
*   Если студент попал к лектору, то он сдаст экзамен только если задавал вопросы и сдал лабы.
*   Если студент не попал к лектору, то для сдачи достаточно или задавать вопросы, или сдать лабы.

Модель нейрона вычисляет взвешенную сумму входов:
$$S = W_1X_1 + W_2X_2 + W_3X_3$$

Выход нейрона \\(Y\\) определяется пороговой функцией активации:
$$f(x) = \begin{cases} 1, & x \ge 0.5 \\ 0, & x < 0.5 \end{cases}$$

Пример весов для простой логики: \\(W_1 = 0.5, W_2 = -0.5, W_3 = 0.5\\).
Для входа \\((1, 1, 1)\\): \\(0.5 \cdot 1 - 0.5 \cdot 1 + 0.5 \cdot 1 = 0.5 \ge 0.5 \rightarrow\\) сдал (1).

### Проблема одного слоя
Один слой проводит в пространстве признаков всего одну разделяющую плоскость. Поэтому задачу, где ответ зависит от комбинации признаков, а не от каждого по отдельности (скажем, лектор не любит тех, кто задавал вопросы, но сданные лабы повышают шанс), персептрон не решает — подобрать веса просто не из чего.

### Скрытые слои
Спасают скрытые слои. Слой \\(Z\\) строит новое признаковое пространство, в котором прежде неразделимая задача становится разделимой.
$$Z_1 = f(W_{11,1}X_1 + W_{12,1}X_2 + \dots)$$
$$Y_1 = f(W_{21,1}Z_1 + W_{22,1}Z_2 + \dots)$$

### Функции активации
Для обучения сети методом градиентного спуска функции активации должны быть дифференцируемы.
*   **Пороговая функция:** ближе всего к биологической модели, но для обучения не годится. В точке порога она не дифференцируема, а всюду вне её производная равна нулю — градиенту неоткуда взяться.
*   **Сигмоида:** Дифференцируемая функция.
    $$f(x) = \frac{1}{1 + e^{-x}}$$
    Производная сигмоиды:
    $$\frac{d\sigma(x)}{dx} = \sigma(x)(1 - \sigma(x))$$

## 2. Обучение нейронной сети

### Обучение одного нейрона
Обучение одного нейрона с сигмоидальной функцией активации ничем не отличается от обучения логистической регрессии. Обучаемые параметры здесь — веса \\(W\\).

### Метод обратного распространения ошибки (Backpropagation)
Для пересчёта весов в многослойной сети необходимо знать ошибку для каждого нейрона. Ошибка для выходного слоя \\(Y_1\\) считается легко, но для скрытых слоёв \\(Z\\) требуется метод обратного распространения.

**Цепное правило (Chain Rule):**
$$\frac{dz}{dx} = \frac{dz}{dy} \cdot \frac{dy}{dx}$$

**Пример вычисления градиента:**
Пусть есть функция \\(f(x, y, z) = (x + y)z\\).
1.  \\(q = x + y\\). Производные: \\(\frac{dq}{dx} = 1, \frac{dq}{dy} = 1\\).
2.  \\(f = zq\\). Производные: \\(\frac{df}{dq} = z, \frac{df}{dz} = q\\).
3.  Итоговые градиенты: \\(\frac{df}{dx} = \frac{df}{dq} \cdot \frac{dq}{dx} = z \cdot 1\\).

**Обновление весов:**
Ошибка — разность между полученным выходом (_actual_) и ожидаемым (_expected_):
$$err = actual - expected$$
Для сигмоиды градиент веса включает производную функции активации:
$$weights\_delta = err \cdot \sigma(x) \cdot (1 - \sigma(x))$$
Обновление веса с learning rate (\\(lr\\)):
$$weight_{new} = weight_{old} - output \cdot weights\_delta \cdot lr$$

Ошибка для скрытых слоёв распределяется пропорционально весам, связывающим их с последующим слоем:
$$err_{hidden} = weight \cdot weights\_delta$$

### Проблемы сигмоиды
Сигмоида дифференцируема и удобна, но у неё три беды, из-за которых в глубоких сетях её почти вытеснил ReLU:
*   На хвостах производная близка к нулю, и в глубокой сети градиент затухает, не дойдя до нижних слоёв.
*   Выход всегда положителен, так что градиенты весов одного нейрона смещены в одну сторону и обучение идёт зигзагом.
*   Экспоненту дорого считать.

## 3. Оптимизаторы

Для минимизации функции потерь используются различные варианты градиентного спуска.

### SGD (Stochastic Gradient Descent)
Базовый метод:
$$x_{t+1} = x_t - \alpha f'(x_t)$$
где \\(\alpha\\) — learning rate.

### SGD with Momentum
Накапливает инерцию движения, чтобы сглаживать колебания:
$$v_{t+1} = \rho v_t + \alpha f'(x_t)$$
$$x_{t+1} = x_t - v_{t+1}$$

### Nesterov Momentum
Улучшенная версия momentum, которая «смотрит вперёд» перед вычислением градиента. Меньше «заносит на поворотах»:
$$v_{t+1} = \rho v_t - \alpha f'(x_t + \rho v_t)$$
$$x_{t+1} = x_t + v_{t+1}$$

### Adagrad (Adaptive Gradient)
Адаптирует learning rate для каждого параметра индивидуально. Веса, которые менялись сильно, меняются меньше:
$$cache_{t+1} = cache_t + f'(x_t)^2$$
$$x_{t+1} = x_t - \frac{\alpha f'(x_t)}{\sqrt{cache_{t+1}} + \epsilon}$$
*Проблема:* \\(cache \to \infty\\), что может остановить обучение.

### RMSProp
Сглаживает изменения кеша, забывая старые значения (экспоненциальное скользящее среднее):
$$cache_{t+1} = \beta cache_t + (1 - \beta) f'(x_t)^2, \quad \beta \in [0, 1]$$
$$x_{t+1} = x_t - \frac{\alpha f'(x_t)}{\sqrt{cache_{t+1}} + \epsilon}$$

### Adam
Комбинация RMSProp и Momentum:
$$v_{t+1} = \gamma v_t + (1 - \gamma) f'(x_t)$$
$$cache_{t+1} = \beta cache_t + (1 - \beta) f'(x_t)^2$$
$$x_{t+1} = x_t - \frac{\alpha v_{t+1}}{\sqrt{cache_{t+1}} + \epsilon}$$
Как отправную точку обычно берут Adam или Nesterov momentum — с ними сеть чаще всего обучается без всякого подбора.

## 4. Нормализация и инициализация

### Нормализация данных
Признаки перед подачей в сеть приводят к сопоставимым масштабам, и на то три причины:
*   Технические ограничения точности дробных чисел.
*   Без нормализации страдают L1 и L2 регуляризация.
*   Ускоряет обучение.
В нейронных сетях это критично, так как каждый слой отображает данные в новое пространство признаков, и при изменении весов меняется распределение новых признаков.

### Инициализация весов
Чем заполнить веса перед обучением — вопрос не праздный, и два очевидных ответа не работают.
*   **Нули:** сеть не обучается, все нейроны слоя одинаковы и получают одинаковый градиент.
*   **Константа:** то же самое, слой вырождается в один нейрон.
*   **Случайные значения:** работают, но масштаб надо подобрать так, чтобы слой не менял дисперсию сигнала.

Для сохранения дисперсии (вывод для линейного слоя):
$$D(s) = D\left(\sum_{i}^{N} w_i x_i\right) = \sum_{i}^{N} D(w_i x_i) = n D(w) D(x)$$
Чтобы \\(D(s) = D(x)\\), необходимо:
$$D(w) = \frac{1}{n}$$
Берём случайные значения и умножаем на \\(\frac{1}{\sqrt{n}}\\) (или используем распределение с дисперсией \\(1/n\\)) — это инициализация Ксавье. Для ReLU половина выходов зануляется, поэтому дисперсию весов берут вдвое больше; такой вариант называют инициализацией Хе (He), и он же стоит по умолчанию в современных фреймворках.

### Batch Normalization
Нормирует активации внутри одного батча — в исходной работе слой ставили перед функцией активации, чтобы распределение входов каждого слоя не уплывало по мере обучения (internal covariate shift). Само это объяснение позже оспорили, но работать слой от этого хуже не стал.

Формула нормализации:
$$\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2}}$$
где \\(\mu\\) и \\(\sigma^2\\) — матожидание и дисперсия в батче.

Далее применяется масштабирующее преобразование с обучаемыми параметрами \\(\gamma, \beta\\):
$$y_i = \gamma \hat{x}_i + \beta$$

На инференсе, когда сеть просто считает предсказание, батча может не быть вовсе, поэтому вместо статистик батча берут накопленные при обучении скользящие средние:
$$\mu_{t+1} = \alpha \times \mu_{batch} + (1 - \alpha) \mu_t$$
$$\sigma^2_{t+1} = \alpha \times \sigma^2_{batch} + (1 - \alpha) \sigma^2_t$$

Batch normalization позволяет ускорить сходимость сети и использовать больший learning rate.

## 5. Регуляризация

### L1 и L2 регуляризация
Штраф за большие веса позволяет бороться с переобучением:
*   **L2:** \\(\|W\|_2^2 = \sum w^2\\)
*   **L1:** \\(\|W\|_1 = \sum |w|\\)
*   **Elastic Net:** Комбинация L1 и L2.

### Dropout
Случайным образом «выключает» некоторые нейроны в процессе обучения. На каждой итерации выключаются разные нейроны.
*   **Интерпретация:** Уменьшение количества признаков.
*   **На инференсе:** нейроны включены все, поэтому выходы масштабируют на долю нейронов, работавших при обучении, — иначе распределение сигнала сдвинется.

### Residual Connection (Остаточные связи)
В очень глубоких сетях градиент может не доходить до нижних слоёв (становиться очень маленьким). С помощью сложения фичей в обход нескольких слоёв (skip connection) получается «проталкивать» градиент до нижних слоёв.

### Аугментация
Искусственное расширение обучающей выборки — те же примеры, но повёрнутые, сдвинутые, зашумлённые. Сеть перестаёт цепляться за случайные особенности конкретных изображений, и качество растёт и на тестовой выборке, и на реальных данных.

## 6. Заключение
Мы прошли путь от одного нейрона до глубокой сети: как считается выход, как через сеть протекает градиент, чем один оптимизатор отличается от другого и почему без нормализации и регуляризации ничего не обучается. Это тот минимум, без которого работа с готовыми фреймворками превращается в перебор настроек наугад.
