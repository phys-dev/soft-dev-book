# Экспресс-курс Python

Помощники помощниками, а писать всё равно предстоит самому. Разберёмся, на чём.

Python — отличный язык общего назначения сам по себе, а с парой библиотек (NumPy, SciPy, Matplotlib, HoloViews) он превращается в полноценную среду для научных вычислений.

Скорее всего, у части читателей уже есть опыт работы с Python и NumPy; для остальных этот раздел станет быстрым экспресс-курсом как по самому языку, так и по его использованию для научных вычислений. Если ты уверенно владеешь базовым синтаксисом, смело пролистывай этот раздел — дальше в книге мы разберём устройство Python гораздо глубже.

Раздел устроен как беглый обзор: SciPy для численных методов — интегрирование, оптимизация, обработка сигналов; HoloViews для интерактивной визуализации; и требования к оформлению кода, которых мы придерживаемся дальше по книге. Основы синтаксиса, NumPy и Matplotlib подробно разобраны в электронной версии — в печатном издании их место заняли темы, которые нельзя прочитать в документации за десять минут.
