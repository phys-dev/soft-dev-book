# Экспресс-курс Python

Помощники помощниками, а писать всё равно предстоит самому. Разберёмся, на чём.

Python — отличный язык общего назначения сам по себе, а с парой библиотек (NumPy, SciPy, Matplotlib, HoloViews) он превращается в полноценную среду для научных вычислений.

Возможно, ты уже писал на Python и работал с NumPy; если нет, этот раздел даст экспресс-курс и по самому языку, и по его применению в научных вычислениях. Если базовым синтаксисом ты владеешь уверенно, смело пролистывай раздел — дальше в книге устройство Python разобрано гораздо глубже.

Устроен раздел как беглый обзор. Сначала SciPy — численные методы: интегрирование, оптимизация, обработка сигналов. Затем HoloViews для интерактивной визуализации. Заканчивается всё требованиями к оформлению кода, которых мы придерживаемся дальше по книге. Основы синтаксиса, NumPy и Matplotlib подробно разобраны в электронной версии — в печатном издании их место заняли темы, которые нельзя прочитать в документации за десять минут.
