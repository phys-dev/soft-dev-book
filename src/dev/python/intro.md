# Научные библиотеки Python

Сам по себе Python остаётся обычным языком общего назначения, никаких научных вычислений в нём нет. Всё, ради чего его берёт физик, живёт в библиотеках, и набор их невелик.

Порядок здесь не случаен, а следует зависимостям. **NumPy** даёт быстрый многомерный массив, на котором стоит всё остальное, и вместе с **pandas**, разбирающимся с таблицами, закрывает хранение и первичную обработку данных. **SciPy** надстраивает над массивом численные методы: интегрирование, решение уравнений, оптимизацию, подгонку кривых, обработку сигналов, преобразование Фурье. Почти всё, что физику приходится считать, там уже написано и проверено. Дальше идёт рисование, где **Matplotlib** остаётся рабочей лошадкой, а **HoloViews** устроен иначе: там описывают, *что* за данные в руках, а не как их рисовать, и библиотека сама решает, каким графиком их показать, делая его интерактивным.

Заканчивается раздел машинным обучением, для которого всё перечисленное служит фундаментом.

Устройство самого языка, включающее объекты, коллекции, функции и классы, разбиралось в теоретической части, в разделе «Погружаемся в Python». Здесь язык уже считается известным.

Если базового синтаксиса ты не знаешь, начни с электронной версии. Там есть отдельные главы с основами языка, с NumPy и с Matplotlib, в печатное издание не вошедшие: их место заняли темы, которые нельзя прочитать в документации за десять минут. На бумаге NumPy разобран в следующей главе вместе с pandas, а Matplotlib в главе про визуализацию.
