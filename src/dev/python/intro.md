# Научные библиотеки Python

Сам по себе Python остаётся обычным языком общего назначения, никаких научных вычислений в нём нет. Всё, ради чего его берёт физик, живёт в библиотеках, и набор их невелик. NumPy даёт быстрые массивы, SciPy добавляет численные методы поверх них, Matplotlib и HoloViews рисуют графики, pandas разбирается с таблицами.

С них и начнём практическую часть. Сперва беглый обзор четырёх библиотек, потом обработка настоящих данных, потом машинное обучение.

**SciPy** закрывает численные методы: интегрирование, решение уравнений, оптимизацию, подгонку кривых, обработку сигналов, преобразование Фурье. Почти всё, что физику приходится считать, там уже написано и проверено.

**HoloViews** устроен не так, как привычный Matplotlib. Там ты описываешь, *что* за данные у тебя в руках, а не как их рисовать; библиотека сама решает, каким графиком их показать, и делает его интерактивным.

Устройство самого языка, включающее объекты, коллекции, функции и классы, разбиралось в теоретической части, в разделе «Погружаемся в Python». Здесь язык уже считается известным.
