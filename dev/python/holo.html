HoloViews

HoloViews — библиотека визуализации, построенная на принципе «аннотируй данные, а не рисуй график». В Matplotlib ты вручную управляешь осями, подписями и линиями; в HoloViews ты описываешь сами данные и их семантику (что здесь аргумент, что — значение, в каких они единицах), а библиотека уже сама решает, как это отобразить. Один и тот же объект можно отрисовать разными бэкендами: интерактивным bokeh, привычным matplotlib или plotly. В итоге меньше кода про пиксели — больше кода про физику.

Установка и импорт

pip install holoviews bokeh

import numpy as np
import holoviews as hv

# Подключаем бэкенд отрисовки; вместо 'bokeh' можно
# указать 'matplotlib' или 'plotly'
hv.extension('bokeh')

В Jupyter объект HoloViews из последней строки ячейки рендерится автоматически — аналог %matplotlib inline не нужен. С бэкендом bokeh ты бесплатно получаешь панорамирование, зум и всплывающие подсказки с точными значениями — для разглядывания экспериментальных данных это незаменимо.

Элементы: данные плюс семантика

Базовый кирпичик HoloViews — элемент: контейнер с данными, который знает свой тип визуализации. hv.Curve — непрерывная зависимость, hv.Scatter — дискретные измерения, hv.Image — величина на регулярной 2D-сетке.

# Затухающие колебания в контуре
t = np.linspace(0, 10, 500)
u = np.exp(-t / 5) * np.sin(2 * np.pi * t)

# Curve — зависимость U(t): первое измерение — аргумент, второе — значение
decay = hv.Curve((t, u), 't', 'U')
decay

Измерениям можно задать человеческие подписи и единицы — они автоматически попадут на оси и в подсказки:

dim_t = hv.Dimension('t', label='Время', unit='с')
dim_u = hv.Dimension('U', label='Напряжение', unit='В')
decay = hv.Curve((t, u), dim_t, dim_u)

hv.Scatter — те же оси «аргумент — значение», но точками. Идеально для экспериментальных данных:

rng = np.random.default_rng(42)

# «Эксперимент»: редкие отсчёты с шумом измерений
t_exp = np.linspace(0, 10, 30)
u_exp = np.exp(-t_exp / 5) * np.sin(2 * np.pi * t_exp)
u_exp += rng.normal(0, 0.05, t_exp.size)

experiment = hv.Scatter((t_exp, u_exp), dim_t, dim_u)

hv.Points внешне похож на Scatter, но семантика другая: обе координаты — независимые ключевые измерения, точки просто живут на плоскости. Классический пример — частицы в фазовом пространстве:

# Пучок электронов в фазовой плоскости (x, px)
x = rng.normal(0, 1.0, 1000)
px = rng.normal(0, 0.3, 1000)

phase_portrait = hv.Points((x, px), ['x', 'px'])

hv.Image — двумерное поле. Например, поперечное распределение интенсивности гауссова лазерного пучка:

grid = np.linspace(-3, 3, 400)
xx, yy = np.meshgrid(grid, grid)
w = 1.2  # радиус пучка, мм

# bounds задаёт физические координаты углов: (лево, низ, право, верх)
intensity = np.exp(-2 * (xx ** 2 + yy ** 2) / w ** 2)
beam = hv.Image(intensity, bounds=(-3, -3, 3, 3),
                kdims=['x', 'y'], vdims='I')

Обрати внимание: нигде выше мы не сказали ни слова о том, как рисовать — только что мы рисуем.

Композиция: + и *

Элементы комбинируются операторами. + кладёт графики рядом (layout), * накладывает их в одних осях (overlay):

# Кривая и карта пучка — бок о бок
layout = decay + beam

# Теория поверх эксперимента — в одних осях
theory_vs_experiment = decay * experiment

Это работает, потому что каждый элемент самодостаточен: HoloViews видит, что у decay и experiment совпадают измерения, и сам выравнивает оси, подписи и легенду. Число колонок в layout задаётся методом .cols():

(decay + experiment + beam).cols(2)

HoloMap и DynamicMap: параметр вместо цикла

Часто нужен не один график, а семейство: как меняется сигнал при изменении частоты, температуры, тока в линзе. В Matplotlib ты рисовал бы цикл из subplots; HoloViews превращает параметр в слайдер.

def waveform(f):
    """Строит кривую затухающего сигнала для частоты f (Гц)."""
    t = np.linspace(0, 2, 1000)
    u = np.exp(-t) * np.sin(2 * np.pi * f * t)
    return hv.Curve((t, u), 't', 'U')


# HoloMap: считаем кривые заранее для дискретного набора частот
frequencies = [1, 2, 5, 10]
hmap = hv.HoloMap({f: waveform(f) for f in frequencies}, kdims='f')
hmap

Рядом с графиком появится слайдер по f. HoloMap хранит все кадры в памяти, поэтому его можно сохранить в самодостаточный HTML — слайдер останется живым даже без Python, удобно отправлять коллегам:

hv.save(hmap, 'waveform.html')

DynamicMap вычисляет кадры лениво, по движению слайдера — спасает, когда параметр непрерывный или каждый кадр дорого считать:

dmap = hv.DynamicMap(waveform, kdims='f').redim.range(f=(0.5, 10.0))

Цена ленивости: DynamicMap требует работающего ядра Python (Jupyter или сервер), в статичный HTML он не сохранится.

Настройка через .opts()

Семантика отделена от оформления: внешний вид задаётся методом .opts() уже поверх готового объекта.

theory_vs_experiment.opts(
    hv.opts.Curve(width=600, height=300, color='black'),
    hv.opts.Scatter(size=6, color='crimson'),
)

# Для Image полезны палитра и шкала цвета;
# logz — логарифмическая шкала (есть и logx, logy для осей)
beam.opts(width=420, height=360, cmap='inferno',
          colorbar=True, logz=True)

Логарифмическая шкала цвета — то, что нужно для пучков и спектров с большим динамическим диапазоном. Учти, что часть опций зависит от бэкенда: width и height в пикселях — bokeh, у matplotlib вместо них fig_inches и aspect. Полный список опций элемента покажет hv.help(hv.Curve).

Экосистема HoloViz

HoloViews — центр целой экосистемы HoloViz. Самая востребованная её часть — hvPlot: интерактивная замена встроенного df.plot() из pandas. Один импорт — и у DataFrame появляется аксессор .hvplot, возвращающий обычные объекты HoloViews, со всеми слайдерами, оверлеями и .opts():

import pandas as pd
import hvplot.pandas  # регистрирует аксессор .hvplot

df = pd.DataFrame({'t': t, 'U': u})
df.hvplot.line(x='t', y='U')  # тот же hv.Curve, но одной строкой

Вторая опора экосистемы — Panel: библиотека для сборки дашбордов и веб-приложений. Она связывает объекты HoloViews, виджеты (слайдеры, кнопки, поля ввода) и текст в единый интерфейс, который командой panel serve app.py превращается в веб-приложение. Так мониторинг установки или разведочный анализ данных становится страницей в браузере — без единой строки JavaScript.
